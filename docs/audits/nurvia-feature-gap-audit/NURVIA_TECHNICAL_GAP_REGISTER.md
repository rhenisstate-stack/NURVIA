# NURVIA — Technical Gap & Defect Register

**Audit Date:** 2026-11-15  
**Scope:** Verified technical defects, broken integrations, missing API contracts, database limitations, security weaknesses, and testing gaps.

---

## 1. Critical & High-Priority Technical Gaps (P0 / P1)

| Gap ID | Feature / Area | Existing State | Expected State | Evidence | Priority | Recommendation |
|---|---|---|---|---|---|---|
| **GAP-001** | Remote Backend Contract Mismatch | `apps/web/.env.local` points `SKEW_LINE_DOTNET_BASE_URL` to `http://108.61.9.189:8008` (`LexmaCasto` / Master Bank), which returns `302 -> /web/restoration/lost` for all NURVIA `/api/*` routes. | Frontend must target a deployed instance of `apps/api` or a verified contract-compatible API gateway. | `apps/web/.env.local`, `apps/web/next.config.mjs`, live `curl` to `108.61.9.189:8008/api/health` (`302`), `docs/NURVIA_REMOTE_API_CAPABILITY_AUDIT.md`. | **P0** | Deploy `apps/api` to a dedicated HTTPS origin and update `SKEW_LINE_DOTNET_BASE_URL`, or implement an explicit BFF adapter if sharing `LexmaCasto`. |
| **GAP-002** | Plaintext HTTP Backend Transport | `SKEW_LINE_DOTNET_BASE_URL=http://108.61.9.189:8008` uses `http://`. | Production auth-bearing traffic must use `https://` so `Secure` cookies and credentials are encrypted in transit. | `apps/web/.env.local`, `apps/web/next.config.mjs:L6-L10`, `AuthController.cs:L118`. | **P0** | Terminate TLS via HTTPS reverse proxy (e.g. `https://explicitbackend.com` once verified) and enforce `requireHttps: true` in production. |
| **GAP-003** | Silent Full-Credit Grading Fallback | `ClinicalCaseStudy` (9) and `ExtendedResponse` (15) unconditionally return `1m` (100%) via `LegacyCredit` for any non-empty JSON. `MultipleTrueFalse`, `MatrixGrid`, `DragAndDrop`, `BowTie` also fall back to `LegacyCredit` if `ContentJsonData` lacks `Correct*` keys. | `ExtendedResponse` and `ClinicalCaseStudy` should either require rubric/manual grading (`PendingManualReview`) or linked sub-item grading; complex types must fail validation if `Correct*` keys are missing. | `apps/api/Nurvia.Application/Questions/QuestionResponseGrader.cs:L176-L275`, `QuestionVersion.cs:L82-L120`. | **P0** | Enforce `Correct*` key presence in `QuestionVersion.Validate()` for new drafts and add `PendingManualReview` attempt state + instructor grading endpoint. |
| **GAP-004** | Missing Rate Limiting on Auth Endpoints | `AuthController.Login` and `Register` have no rate-limiting middleware or account lockout. | Brute-force and credential-stuffing protection via ASP.NET Core `RateLimiter` / lockout policy. | `apps/api/Nurvia.Api/Program.cs`, `apps/api/Nurvia.Api/Controllers/AuthController.cs:L75-L125`. | **P0** | Add `builder.Services.AddRateLimiter(...)` with strict sliding-window policies on `/api/auth/login` and `/api/auth/register`. |
| **GAP-005** | Missing Password Recovery & Change Password | No forgot-password, reset-password, or change-password endpoints or UI. | Self-service password reset (time-limited token + email delivery) and authenticated password change. | `apps/web/app/sign-in/page.tsx`, `apps/api/Nurvia.Api/Controllers/AuthController.cs`. | **P0** | Add `PasswordResetToken` entity, `POST /api/auth/forgot-password`, `POST /api/auth/reset-password`, `POST /api/auth/change-password`, and UI flows. |
| **GAP-006** | Broken Navigation Links to `/exam-session` | `nclex/page.tsx:L74` links to `/exam-session?track=RN&category=NCLEX`; `learner/planner/page.tsx:L59` and `learner/saved-questions/page.tsx:L56` link to `/exam-session` without `examId` or `attemptId`. | `/exam-session` requires `examId` or `attemptId`; otherwise it renders error `"Choose a published exam before opening an exam session."` | `apps/web/app/exam-session/page.tsx:L177-L179`, `nclex/page.tsx:L74`, `planner/page.tsx:L59`, `saved-questions/page.tsx:L56`. | **P1** | Route NCLEX/planner CTAs to `/exams?track=RN` or `/learner/custom-practice?pathway=RN`, or support `?examId=` lookup. |
| **GAP-007** | Admin Audit & RBAC UIs Disconnected from Existing Backend | `GET /api/audit-logs` (`AuditLogsController.cs`) and `POST /api/auth/assign-role` (`AuthController.cs`) exist and are tested, yet `/admin/audit` and `/admin/rbac` render hardcoded mocks. | `/admin/audit` should call `nurviaApi.getAuditLogs()`; `/admin/rbac` should list users and call `/api/auth/assign-role`. | `apps/web/app/admin/audit/page.tsx:L22-L59`, `apps/web/app/admin/rbac/page.tsx:L18-L43`, `AuditLogsController.cs`, `AuthController.cs:L171`. | **P1** | Wire `/admin/audit` to `nurviaApi.getAuditLogs` and add `GET /api/users` + wire `/admin/rbac`. |
| **GAP-008** | 14+ Mock / Presentation-Only Pages Exposed in Navigation | `/learner/ai-tutor`, `/learner/flashcards`, `/learner/care-plans`, `/learner/community`, `/learner/planner`, `/learner/guides`, `/learner/saved-questions`, `/learner/subscription`, `/admin`, `/admin/analytics`, `/admin/cases`, `/admin/learners`, `/admin/plans`, `/admin/question-types`, `/admin/settings`, `/admin/taxonomy` show static mock data or non-functional buttons. | Production navigation should only expose working features or clearly mark/gate unimplemented modules until backed by real APIs. | `apps/web/components/layout/learner-shell.tsx`, `admin-shell.tsx`, and respective `page.tsx` files. | **P1** | Implement backend modules in phased roadmap or remove/gate mock routes before public launch. |
| **GAP-009** | Dosage Calculator Division-by-Zero & Missing Calculators | `learner/calculators/page.tsx` computes `(volume * dropFactor) / (timeHours * 60)` with no guard for `timeHours <= 0` (produces `Infinity`/`NaN`). Hub advertises pediatric weight-based and titration calculators that do not exist. | Input validation (`timeHours > 0`, `volume >= 0`) and implemented pediatric/titration tabs. | `apps/web/app/learner/calculators/page.tsx:L16-L17`, `apps/web/app/learner/hub/page.tsx:L43`. | **P1** | Add input guards and implement pediatric mg/kg and weight-based infusion calculators. |
