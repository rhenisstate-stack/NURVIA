# Security Deviation Register

This register records every instance where Qlex's implementation was adapted in NURVIA to preserve security boundaries, application identity, or safe session handling.

| ID | Qlex Source Path | NURVIA Destination Path | Unsafe / Incompatible Qlex Behavior | NURVIA Secure Implementation |
|---|---|---|---|---|
| SEC-001 | `src/lib/config/config.ts` | `apps/web/lib/config/config.ts` | `APP_KEY` fell back to `"WEBSITE_1"` and was readable on client if imported; `SEO` fell back to `skewblanc.com`. | `APP_KEY` is strictly server-only (`typeof window === "undefined" ? process.env.SKEW_LINE_APP_KEY \|\| "" : ""`) with no `"WEBSITE_1"` fallback; `SEO` falls back to `https://nurvia-black.vercel.app`. |
| SEC-002 | `src/lib/config/siteHeaders.ts` | `apps/web/lib/config/siteHeaders.ts` | Used `APP_KEY` with `"WEBSITE_1"` fallback. | Fails closed (`throw new Error(...)`) if `SKEW_LINE_APP_KEY` is missing on the server. |
| SEC-003 | `src/lib/utils/sessions/generateSystemUserSessionCookies.ts` | `apps/web/lib/utils/sessions/generateSystemUserSessionCookies.ts` | Wrote/read JS-accessible session cookies (`skew_blanc_session_line`, `skew_blanc_session_badge`) via `document.cookie`. | Client-side auth cookie writes/reads are disabled (no-ops); NURVIA manages auth sessions exclusively via `HttpOnly` server cookies (`nurvia_casto_line`, `nurvia_casto_badge`, `nurvia_casto_dashboard`). |
| SEC-004 | `src/lib/services/auth/loginService.ts` | `apps/web/lib/services/auth/loginService.ts` | Wrote `casto_line` / `casto_badge` into `document.cookie` via `writeAuthSessionCookies`. | Relies on `/api/auth/login` setting `HttpOnly` server cookies; `getSessionFromCookies` returns empty client-side map. |
| SEC-005 | `src/lib/services/auth/socialService.ts` | `apps/web/lib/services/auth/socialService.ts` | Hardcoded Qlex challenge strings (`learner.login.skew8lancasto`, `register-skew8@lancasto`) in client code. | Removed hardcoded Qlex challenge strings; challenges are attached server-side via `lib/auth/temporaryChallenge.ts`. |
| SEC-006 | `src/middleware.ts` | `apps/web/middleware.ts` | Set `x-site-session` cookie without `secure: process.env.NODE_ENV === 'production'`. | Preserved NURVIA's `middleware.ts` with `secure: process.env.NODE_ENV === 'production'` and NURVIA domain resolution. |
| SEC-007 | `src/lib/services/partial/helper/systemSessionHeaders.ts` | `apps/web/lib/services/partial/helper/systemSessionHeaders.ts` | Read `skew_blanc_session_badge` and `skew_blanc_session_line` from `document.cookie` into `x-casto-line` / `x-casto-badge`. | Returns `{}`; `HttpOnly` auth cookies are sent automatically and attached server-side by `lexmaCastoRequest`. |
| SEC-008 | `src/lib/utils/sessions/clearSystemUserSessionCookies.ts` | `apps/web/lib/utils/sessions/clearSystemUserSessionCookies.ts` | Targeted JS-readable `skew_blanc_session_*` cookies via `document.cookie`. | No-op on client; `/api/auth/logout` clears `HttpOnly` `nurvia_casto_*` cookies server-side. |
| SEC-009 | `src/app/(web)/auth/*` (modals, `page.tsx`) | `apps/web/app/(web)/auth/*` | Hardcoded Qlex challenge strings (`skew8lancasto`) in client components. | Stripped hardcoded Qlex challenges from client code; `/api/auth/*` attaches challenges server-side. |
| SEC-010 | `src/app/api/auth/*`, `src/app/api/users/*` | `apps/web/app/api/auth/*`, `apps/web/app/api/users/*` | Read `x-casto-line` / `x-casto-badge` from client headers and set non-HttpOnly `casto_*` cookies. | Bridged via `getNurviaCastoSessionHeaders()` from `HttpOnly` `nurvia_casto_*` cookies; `onetap` uses `getTemporaryChallenge()` and `nurvia_casto_*` cookies. |
| SEC-011 | `src/app/dashboards/*/auth/{login,register}/page.tsx` | `apps/web/app/dashboards/*/auth/{login,register}/page.tsx` | Hardcoded Qlex challenge literals (`skew8lancasto`, `skew8@lancasto`) in client login/register pages across all 6 programs. | Stripped hardcoded Qlex challenge literals from client pages; server-side `/api/auth/login` and `/api/auth/register` attach challenges. |
